Repères pour fixer un prix

  1. Recherche plusieurs articles identiques ou très proches.
  2. Compare la marque, le modèle, la taille, l'état et les photos.
  3. Regarde les prix affichés, sans les confondre avec les prix réellement vendus.
  4. Décris honnêtement l'état et ne promets pas une vente rapide.

Sauvegarde et confidentialité

Les données sont enregistrées dans le stockage local de ce navigateur. Elles ne se synchronisent pas automatiquement entre ton téléphone et ton ordinateur.

Garde une copie de ta sauvegarde dans un endroit sûr. N'enregistre pas de mot de passe, adresse, coordonnées bancaires ni informations privées d'acheteurs.

Limites actuelles

  • Pas de connexion ni de publication automatique sur Vinted.
  • Pas de synchronisation cloud ou de compte utilisateur.
  • Le générateur de texte fonctionne localement avec un modèle de rédaction, pas avec une IA externe.
  • Pour une vraie IA en ligne, il faudra créer un service sécurisé et un compte API avec l'aide d'un adulte ; ne colle jamais de clé secrète dans cette page.
